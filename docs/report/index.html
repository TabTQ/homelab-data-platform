Why I built it

The bronze, silver and gold pattern is everywhere in Databricks work, and I wanted hands-on practice with it instead of only reading about it. I started with no Databricks or PySpark experience. This project is how I learned both.

I picked data I already had: the metrics my own Raspberry Pi and Proxmox homelab produce. The goal was a pipeline that behaves like a real one. Raw files land in cloud storage, a trigger starts the load, bronze keeps everything as it arrived, silver cleans and deduplicates with PySpark, and gold serves a dashboard through SQL stored procedures.

The twist is that my Proxmox host is only on when I need it. So the pipeline also has to decide when to wake the hardware, collect the data, and put it back to sleep.

Scope. This is a homelab project built to learn the tools. Each run moves about 5 MB, so it shows patterns, not scale. I describe it that way on purpose.

What it does

01 COLLECT

Pull history from Prometheus

A small extractor in an LXC runs 11 PromQL queries and pulls the last 15 days at 5-minute steps, one raw JSON file per metric per day.

02 LAND

Upload, then trigger

Files go to a Unity Catalog Volume. A marker file is written last. A file-arrival trigger starts a three-task Workflow with no schedule.

03 REFINE

Bronze, silver, gold

Auto Loader appends raw JSON to bronze. PySpark explodes, cleans and dedupes into silver. A SQL stored procedure merges hourly and daily tables into gold.

04 SERVE

Dashboard and power control

An AI/BI dashboard reads gold. A scheduler on the Pi wakes Proxmox through my Homelab Hub only when the data is stale, then shuts everything down.
